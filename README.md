# 贝斯每日练习

一个在自己电脑上运行的中文贝斯练习工具，把听觉参照、指板音级、调式转换和即兴连接起来。默认使用五弦贝斯定弦，可在「每日路线」设置定弦、琴品和速度。

[下载最新版 Windows 便携包](https://github.com/genfanyulinteng-dotcom/bass-practice/releases/latest) · [源码仓库](https://github.com/genfanyulinteng-dotcom/bass-practice)

包含这些练习：

- **七层学习顺序**：建立听得见的参照 → 遮图检索与已知参照迁移 → 同音集重新建立中心 → 同主音替换音 → 保留底层参照的上层结构 → 中心与音阶同时变化 → 未知参照与真实音乐。每层都有具体任务、表现记录和卡住时的简化方法。
- **33 种音阶与调式**：大调、爵士旋律小调、和声小调的各七种模式，大小五声与布鲁斯、两种 Bebop、全音与两种减音阶，以及和声大调、双和声大调、匈牙利小调。
- **9 条转换路径**：同主音少量变化、同音集换中心、中心与音阶一起变、爵士色彩与解决、持续低音与重音分组、对称音集共同音、五声到布鲁斯、旋律小调同音集换中心、小调六级与七级比较。也可以自定各段参照音和音阶。
- **音级地图与 Jam**：指板定位、遮图回忆、共同音和变化音比较、节拍与伴奏、受控盲听，以及 42 次每日路线。

从「练习顺序」开始，每次只增加一个难点。点击定位的正确记录、受控听觉题的核对结果，以及自己对实琴演奏的观察分别呈现；勾选练完不代表系统认证已经掌握。

工具不自动监听麦克风或贝斯输入，也不自动评判音准、节奏或演奏质量。陌生素材的中心候选由你听辨和记录；证据不足时，可以保留多个解释，继续用具体音高、音程与动机工作。

**Windows 上直接使用**

1. 打开[最新版发布页](https://github.com/genfanyulinteng-dotcom/bass-practice/releases/latest)，下载 Windows x64 便携 ZIP 附件。v1.0.0 的附件名为 `bass-practice-1.0.0-windows-x64.zip`，并提供对应的 `.sha256` 校验文件。
2. 将整个 ZIP 解压到有写入权限的本地文件夹，进入解压得到的 `bass-practice` 目录。不要在压缩包预览中直接运行，也不要只取出启动文件。
3. 双击 `开始练习.cmd`。它会启动本机服务并在浏览器中打开 `http://127.0.0.1:5175`。
4. 双击一次 `创建桌面入口.cmd`，以后可直接用桌面的「贝斯每日练习」快捷方式打开。搬动整个应用文件夹后，再运行一次该命令重建入口。
5. 需要退出后台服务时，双击 `关闭工具.cmd`。仅关闭浏览器标签页不会关闭服务。

Windows 发布包自带 Node.js 运行时，无需安装 Node.js 或 Codex，也无需登录。日常练习可离线使用；工具内的外部理论资料链接需要联网。程序只监听本机回环地址，不使用 GitHub Pages，也没有配套的在线网页部署。

**进度与搬家**

进度和设置保存在应用文件夹内的 `data` 目录，主要文件为 `progress.json` 和 `lab-progress.json`；保存时还会生成备份。源码构建后的默认位置是 `dist/bass-practice/data`。进度不上传 GitHub，也不随浏览器账户同步。「陌生素材」草稿为临时记录，离开该模块会清空，需要长期保留时请自行另存。

公开发布包不包含个人练习记录，从初始空记录开始。保留自己的进度时，先关闭工具，再备份整个 `data` 目录。更新到新解压的应用文件夹后，将备份放回新文件夹中的 `data`；搬家时也可以在关闭工具后移动整个应用文件夹。不要把自己的数据目录、运行日志或运行中的服务控制文件提交到公开仓库。

**从源码运行**

需要符合 `package.json` 要求的 Node.js（当前为 22.13.0 或更高版本）和 npm。首次安装依赖需要联网。在仓库根目录依次运行：

```sh
npm ci
npm run check
npm run build
npm test
npm start
```

构建输出位于 `dist/bass-practice`，`npm run build` 本身不附带 Node.js 运行时。启动后手动打开 `http://127.0.0.1:5175`；终端中按 `Ctrl+C` 停止这次启动的服务。构建会保留该目录中已有的 `data`；自行清理或替换整个构建目录前，仍需备份进度。默认端口一次只能供一份工具使用，启动另一份前请先关闭正在运行的一份。

在 Windows x64 上生成便携发布包：

```sh
npm run package:windows
```

此命令会重新构建，将当前 Windows x64 Node.js 运行时复制到包内，并联网获取对应 Node.js 版本的完整许可文件。打包需要网络，生成的成品可以离线运行。v1.0.0 的输出为 `release/bass-practice-1.0.0-windows-x64.zip` 和 `release/bass-practice-1.0.0-windows-x64.zip.sha256`；版本号取自 `package.json`。若同名 ZIP 已存在，命令会停止，请先保留或移走旧包再重建。

打包脚本按白名单复制程序文件，不复制个人 `data`、日志或服务控制文件。不要把自己已经使用过的应用目录直接压缩后公开发布。
